# El Joyero

*Jewel Box · NGC 4755 · Cúmulo abierto*

Pequeño cúmulo pegado a Mimosa, en la Cruz del Sur. Con telescopio se ven estrellas azules y una roja, como joyas.

*It is young for a cluster: about 14 million years.*
