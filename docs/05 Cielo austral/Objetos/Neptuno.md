# Neptuno

*Neptune · Planeta*

El planeta más lejano. Invisible a simple vista: se necesita telescopio para verlo como un puntito azul.

## Datos
| | |
|---|---|
| Duración del año | 165 años |
| Lunas conocidas | 16 |
| Diámetro | 49.244 km |
| Se ve | Telescopio |

## Cuándo verlo
Su posición cambia cada noche. La app la calcula en vivo (ver [[Motor astronómico]]); las fechas destacadas están en [[Calendario astronómico 2026–2027]].

> [!tip] ¿Sabías que…?
> Fue descubierto en 1846 con matemáticas, antes de ser visto.

## English
The farthest planet. Invisible to the eye: you need a telescope to see it as a tiny blue dot.

*It was discovered in 1846 by mathematics before anyone saw it.*
