# Saco de Carbón

*Coalsack · C 99 · Nebulosa oscura*

Una mancha negra junto a la Cruz del Sur. No es un hueco: es una nube de polvo que tapa las estrellas de atrás.

## English
A black patch beside the Southern Cross. It is not a hole: it is a dust cloud hiding the stars behind it.

*Andean peoples saw figures in the dark patches of the Milky Way.*
