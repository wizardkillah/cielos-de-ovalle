# Prototipos anteriores

Las seis versiones previas se conservan en `Prototipos anteriores/` como referencia histórica. **No deben usarse con público**: contienen los errores descritos en [[Bugs encontrados]] y [[Correcciones de contenido]].

| Archivo | Qué era | Estado |
|---|---|---|
| `star-map.html` | Mapa 2D inicial | Reemplazado |
| `stellarium-pro.html` | Mapa 2D con Sol, Luna, planetas y tiempo | Luna mal calculada |
| `solar-system-3d.html` | Sistema Solar holográfico (Three.js) | Requiere internet |
| `milkyway-3d.html` | Cinco escalas hasta el Grupo Local | Órbitas no reales |
| `solar-system-hd.html` | Planetas con texturas procedurales | Órbitas no reales |
| `observatorio-app.html` | App móvil bilingüe | Sin sensores; errores de contenido |

Resumen de qué aportó cada una: [[Historial de versiones]].
